CHEST COUNTER  -  by @hypr.7
A small on-screen counter for Fortnite chests.

HOW TO USE
  1. Run ChestCounter.exe (no install needed).
  2. Set Fortnite to "Windowed Fullscreen" so the counter can show on top of the game.
  3. Keys (work while the game is focused):
       F8 = +1 chest     F7 = -1 chest     F9 = reset to 0
  4. Drag the counter to move it. Drag its right or bottom edge to resize it.
  5. Click the gear at the top (or right-click) for Settings: change the keys, type in a number,
     or turn the effects off. Every 100 chests there's a gold celebration.

TASKBAR
  While it's running, right-click its taskbar icon and choose "Pin to taskbar".

YOUR DATA
  Your count and settings are saved in  %AppData%\ChestCounter  (paste that into the Explorer address bar).
  Delete that folder to start fresh.

WINDOWS WARNING
  Windows may say "Windows protected your PC" because the app isn't signed with a paid certificate.
  Click "More info" > "Run anyway". The app only checks whether your chosen keys are pressed;
  it has no network code and doesn't touch the game.
