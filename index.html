Chest Counter

A small always-on-top overlay that counts your Fortnite chests. Built for streams.

Download for Windows

Free and open source · Windows 10 / 11 · All releases

What it does

Hotkey countingAdd or remove a chest with a key, even while the game is focused.
Celebration every 100A gold burst when you hit 100, 200, 300 and so on.
Made for streamsResizable, draggable, and it shows on top of the game.
Yours to set upChange the keys, type in a number, turn effects off.

Get started

  1. Click Download for Windows and extract the zip.
  2. Run ChestCounter.exe. No install needed.
  3. Set Fortnite to Windowed Fullscreen so the counter can show on top of the game.
  4. Optional: right-click its taskbar icon and choose Pin to taskbar.

Default keys

F8 add a chest
F7 remove a chest
F9 reset to 0

Change them any time from the gear at the top of the counter.

Is it safe?

Windows may warn you. The app isn't signed with a paid certificate, so Windows can say “Windows protected your PC.” Click More info, then Run anyway.

The app only checks whether your chosen keys are pressed and saves your count in a small file. It has no network code and doesn't touch the game. The full source is on GitHub, and every release is built there from that source, so you can read it yourself.
